# Предобработка данных о рынке видеоигр

Учебный проект по подготовке исторических данных о видеоиграх за 2000–2013 годы для команды игры «Секреты Темнолесья».

## Цель проекта

Проверить качество исходных данных, провести предобработку и подготовить актуальный срез для дальнейшего исследования игровой индустрии.

## Что сделано

* изучена структура исходного датасета;
* названия столбцов приведены к стилю `snake_case`;
* исправлены типы данных;
* обработаны пропуски;
* найдены и удалены дубликаты;
* подготовлен срез за 2000–2013 годы;
* добавлены категории пользовательских и экспертных оценок;
* определены семь платформ с наибольшим количеством выпущенных игр.
